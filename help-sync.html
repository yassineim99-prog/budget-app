Nisba

Sync between two phones

Free, no credit card. Your budget is saved in your own Google Drive, protected by a password. Do this once, on a computer if possible (about 10 minutes). Only one person needs to do it. The other phone joins with a link.

1Your sync password

We made a random password for you. It's already inside the script below. Write it down.

2Create the Google script

  1. Open script.google.com and sign in. Click New project.
  2. Rename it (top left) to Budget sync.
  3. Delete everything in the editor, then copy the script below and paste it in:
    Copied ✓
    4. 

  4. Click 💾 Save.
    5. 

  5. In the menu next to ▷ Run choose authorize, then click Run → Review permissions → your account.
    If Google says “Google hasn't verified this app”: tap Advanced → Go to Budget sync (unsafe) → Allow. It's your own script, and it only touches your own Drive.
    6. 




3Publish it as a web app
    

  1. Deploy → New deployment → click ⚙ → Web app.
    2. 

  2. Execute as: Me. Who has access: Anyone. The password still protects your data.
    3. 

  3. Click Deploy and copy the Web app URL (it ends in /exec).
    4. 




4Connect your phones
    

  1. In Nisba: Settings → Sync between phones. Paste the Web app URL and the password, then tap Connect.
    2. 

  2. Tap Copy link for the other phone and send it to your partner (e.g. on WhatsApp).
    3. 

  3. On their phone: install Nisba, open Settings, paste the link under “Got a link from the other phone?”, then tap Connect with link.
    4. 

  4. On each phone, choose who it belongs to under This phone belongs to.
    5. 

The link contains the password. Only send it to the person you share the budget with.
